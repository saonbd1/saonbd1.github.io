How to create and publish the Google Sheet

  1. Create a new Google Sheet (https://sheets.google.com) and name it "light-seo-tools - Requests".
  2. Create these columns in row 1: Timestamp, Email, Report Type, Uploaded File (Y/N), Notes, Report Link, Status, Admin Notes
  3. Populate it with a test row to make sure it works.
  4. To embed the sheet here, publish the sheet or create a shareable link:
    • Publish to web: File → Publish to the web → select the sheet/tab → Publish → copy the provided link. Use the 'Embed' option to get an iframe URL, or use the normal published link.
    • OR share with anyone with the link: Share → Change to 'Anyone with the link' and set to 'Viewer' → Copy link (note: this link is not directly embeddable without publish; prefer Publish to web for embedding).
  5. Paste the published URL (the iframe/published link) into _config.yml under admin_sheet_url and push to GitHub. The admin page will then show the embedded sheet.

Note: Publishing the sheet makes it viewable by anyone with the link. The login page (login.html) hides this dashboard, but a published sheet URL still opens for anyone who has it, so keep client data out of published sheets or serve it from an authenticated source.
