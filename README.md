# Light SEO Tools

A lightweight, static SEO toolkit: quick browser-side helpers plus Scrapebox-backed reports, delivered by private link.

## Browser Helpers (Free)

- Duplicate URL Finder - Remove repeated URL entries locally in your browser
- Meta Tag Generator - Generate basic title and description tags for HTML
- Link Extractor - Extract internal URLs from a starting page up to three crawl levels deep
- Redirect Checker - Check URLs for 301, 302, and other redirect status codes instantly
- Robots.txt Checker & Generator - Inspect a site's robots.txt and generate custom directives
- Anchor Text Checker - Extract anchor text and target URLs from page HTML
- Article Scraper - Pull readable text out of a page's HTML
- Bing Meta Scraper - Extract title and meta tags from HTML
- Bing Image Grabber - Collect image URLs from page HTML
- Dofollow Link Tester - Detect dofollow vs nofollow links
- Outbound Link Checker - Find external links in a page's HTML
- Merge Duplicate Links - Merge two URL lists and remove duplicates
- Sitemap Scraper - Fetch a sitemap.xml and extract its URLs
- Alive URL Checker - Check which URLs are still reachable
- Bandwidth Meter - Estimate the download size of a URL
- OCR Image to Text - Convert image to text using client-side optical character recognition
- Trim URL to Domain - Strip URLs down to their domain
- Trim URL to Root - Strip URLs down to their origin
- Trim URL to First Folder - Keep the origin plus the first path segment
- Name Generator - Generate random names for placeholder data
- Email Generator - Generate random email addresses
- Bulk Anchor Text Creator - Generate HTML anchors from URLs and text
- Remove Duplicate Entries - Deduplicate any text list
- Split Text File - Break a list into smaller parts
- Sort Text Files - Sort lines alphabetically or numerically
- Extract URL Links - Pull all URLs from text or HTML
- Legal Page Generator - Generate Terms, Privacy Policy, and Affiliate Disclosure text

- Duplicate URL Report - Receive a cleaned unique-URL export in HTML, TXT, CSV, or XLSX
- Meta Tag Scraper - Extract URL, title, description, and optional page fields
- Broken Link Checker - Request a crawl report for broken and redirected links
- Alexa Rank Checker - Check global and country rank for domains
- Domain Resolver Tool - Resolve domains to IPs and DNS records
- Mass URL Shortener - Shorten a list of URLs in bulk
- Social Account Scraper - Find social profiles linked to domains
- Vanity Name Checker - Check username availability across platforms
- Whois Scraper - Extract WHOIS registration details
- Tdname Scrapper - Scrape domain listings and pricing
- Google Index Checker - Check whether URLs are indexed in Google
- Bing Index Checker - Check whether URLs are indexed in Bing
- Check Unregistered Domain - Find domains still available to register
- Bulk Nameserver Extractor - Extract nameservers for domains

## Protected admin area

The admin dashboard (`admin.html`) is gated behind `login.html`, which signs
admins in with Supabase Auth from `assets/auth.js`. Set `supabase_url` and
`supabase_anon_key` in `_config.yml` before signing in — step-by-step setup is in
INSTRUCTIONS.md, section 8.

Because Jekyll serves static files, this is a user-experience gate: keep private
data behind Row Level Security policies or a JWT-protected Supabase function
rather than relying on the hidden page.

## SEO content structure

Each page carries its own metadata and long-form content in front matter, so nothing is
duplicated across the 45 published pages:

- `seo_title` — overrides the `<title>` tag when the plain `title` is not descriptive enough.
- `description` — the meta description, reused for Open Graph and Twitter cards. Keep it between 70 and 165 characters.
- `tool: true` — marks an interactive browser tool and emits `WebApplication` structured data.
- `guide.what` / `guide.steps` / `guide.tips` — the "how to use it" copy rendered by `_includes/tool-guide.html`, also emitted as `HowTo` structured data.
- `faq` — a list of `q` / `a` pairs rendered as an accessible FAQ block and emitted as `FAQPage` structured data.
- `related` — internal links rendered in the guide sidebar (title + url).
- `noindex: true` — used by `admin.html` and `login.html`; these pages are also skipped in the sitemap.

`_layouts/default.html` adds the canonical URL, robots meta, Open Graph/Twitter tags and the
schema.org graph (Organization, WebSite, WebPage, BreadcrumbList, WebApplication, HowTo,
FAQPage). `robots.txt` and `sitemap.xml` are generated by Jekyll from `site.html_pages`;
add new pages anywhere and they are picked up automatically.

Run `bundle exec jekyll build` and check `_site/sitemap.xml` after adding a page.

## Local development

This is a static Jekyll site with no Node build step. Install Jekyll and run `bundle exec jekyll serve` to preview locally at http://127.0.0.1:4000/light-seo-tools/.
